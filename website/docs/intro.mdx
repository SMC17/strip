# Strip

Trust and evidence operating system for computational aerospace engineering.

</div>

The simulator is one evidence producer. Assurance, HIL, flight test, and external tools (JSBSim, FMI, OpenVSP, PX4) are others. The asset is the machine-verifiable link between a decision, the models used, their domains, uncertainties, and supporting evidence.

## Start here

```sh
cd /home/user/sovereign-physics/strip   # full path — not ~/strip or zoxide `strip`
# Zig 0.16.0 required — see Reproducible build
zig build verify

cd website
npm ci && npm start   # http://localhost:3000/strip/
```
